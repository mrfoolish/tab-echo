# Tab Echo

[English README](README.md)

Tab Echo 是一个本地优先的 Chrome 已关闭标签页工具，用于查找并重新打开真实关闭事件。它严格隔离常规和无痕浏览上下文，将随窗口一起关闭的多个标签页保存为有序 Group 记录，并提供紧凑弹窗和完整管理页面。它是增强版“重新打开关闭的标签页”工具，不是完整浏览器历史管理器。

## 功能

- 分别捕获常规窗口和无痕窗口中的关闭事件，不在两个上下文之间暴露数据。
- 单个关闭标签页保存为单条记录；整窗关闭的多个标签页保存为一个有序 Group 记录。
- 按标题和网址搜索；Group 搜索只展示精确命中的子标签页，同时保留完整 Group 快照。
- 无搜索词时的汇总统计全部底层记录（含标签组和被展示去重隐藏的单标签记录），弹窗入口只显示不带数量的“打开完整列表”；只有搜索状态才显示带匹配数量的“查看全部结果”。
- 重新打开单个标签页或整个 Group；重新打开不会消耗或修改关闭记录。
- 可排除指定域名（包括其子域名），使其今后不再记录；新增规则命中已有数据时，保存流程会统一预览影响，并允许保留已有记录或同时移除命中项。
- 将单条记录、当前搜索结果或全部记录软删除到同一浏览上下文的回收站；可移回关闭记录但不会重新打开网页，也可直接移除且无法恢复。
- 完整页面支持关闭记录、回收站、分页、搜索和设置；关闭记录可按关闭时间或域名查看，按域名查看时批量操作仅作用于当前域名。
- 弹窗默认展示 10 条结果，可在设置中配置为 1–200 条，适合快速搜索和操作。
- 支持浅色、深色、跟随系统主题，以及中英文界面。
- 分别展示常规 IndexedDB 记录与无痕记录/设置数据的存储压力，不把两套无关容量相加。
- 采用混合清理：先按保存期限清理，再删除超过条数上限的最旧记录；回收站只按期限清理，不受数量限制。

## 默认保存设置

- 每个浏览上下文最多保存 **10,000** 条关闭记录，一个 Group 只计一条。
- 关闭记录保存天数：**不限制**，即永久保留。
- 回收站保留期限：**3 天**，没有数量限制。

所有保留设置都可以留空。条数留空表示不限制；关闭记录或回收站天数留空表示永久保留。所有情况仍受浏览器存储空间限制，扩展不会申请 `unlimitedStorage`。非空值必须是正整数。保存前会预览永久删除影响：没有删除影响时直接保存，有影响时通过页面内提示再次确认。

排除域名按每行一个填写，`example.com` 同时匹配该域名及其子域名。新增规则始终影响今后关闭的标签页；若命中已有数据，同一个保存提示会提供**仅保存规则**和**保存并移除命中项**。移除只针对本次新增规则和当前常规或无痕上下文，Group 中未命中的标签页会保留，命中项不会移入回收站。

## 安装与使用

1. 打开 `chrome://extensions`。
2. 开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择本仓库的 `extension/` 目录。
4. 关闭一个标签页，再从工具栏打开 Tab Echo；弹窗会展示配置数量的最近记录或匹配结果。
5. 使用**重新打开**打开单个标签页，或使用**全部重新打开**打开完整 Group；使用**移至回收站**进行可恢复删除，或使用**直接移除**立即移除关闭记录且无法恢复。
6. 从弹窗进入完整页面，浏览全部记录、管理回收站或修改设置。

移至回收站、移回关闭记录，以及直接移除单条关闭记录或回收站记录均无需确认。弹窗中的“移入回收站（X）”只处理当前展示项；“直接移除”可选择当前展示项或当前条件下的全部结果。批量直接移除、会清理数据的设置变更和**清空回收站**使用页面内二阶段确认，明确显示受影响的记录数与标签页数，不调用浏览器原生确认弹窗。

### 无痕窗口

在 `chrome://extensions` 中打开 Tab Echo 详情并开启**允许在无痕模式下运行**。清单使用 `"incognito": "split"`，Chrome 会为无痕窗口运行独立扩展上下文。关闭记录和回收站严格隔离，偏好设置共享。常规大列表使用 IndexedDB；无痕记录使用按上下文隔离的持久化本地存储，避免关闭最后一个无痕窗口时被 Chrome 连同无痕 IndexedDB 一起销毁。

## 数据迁移

旧版本地数据会自动执行一次迁移。旧默认值 `65,536 / 30 天` 会迁移为 `10,000 / 不限制天数`；用户明确自定义过的配置保持不变。有效的常规和无痕记录会进入独立存储分区，损坏的旧记录会被跳过且不会阻止启动。迁移成功后，下次打开 Popup 或完整页面会显示一条全扩展共享的一次性摘要，并说明无法恢复的损坏记录数。

## 隐私与权限

所有数据只保存在浏览器本地：常规记录使用 IndexedDB，无痕记录和共享设置使用 `chrome.storage.local`。Tab Echo 仅存储关闭事件所需的元数据，例如标题、网址、图标网址、时间戳、顺序和 Group 元数据。扩展不会采集页面内容、表单状态、滚动位置、关闭事件之外的浏览历史或跨设备数据。

清单仅申请以下权限：

- `storage`：在本地保存设置、关闭记录、回收站和迁移状态。
- `tabs`：监听标签页生命周期并重新打开保存的标签页。
- `alarms`：在界面未打开时也能执行每日保存期限清理。

## 项目结构

```text
.
├── extension/
│   ├── background.js                 # MV3 Worker、事件、alarm 与消息协议
│   ├── lib/
│   │   ├── close-tracker.js          # 标签页/窗口快照与关闭分组
│   │   ├── history-store.js          # 纯历史、搜索、保存规则与回收站模型
│   │   ├── storage-repository.js     # 设置、元数据和旧数组迁移
│   │   ├── indexeddb-repository.js   # 分代 IndexedDB 记录与索引
│   │   ├── indexeddb-migration.js    # 可恢复的本地数组迁移
│   │   └── indexeddb-storage-repository.js # 原子切换数据代并兼容原仓储接口
│   ├── dashboard.html/.css/.js       # 完整关闭记录、回收站与设置页面
│   ├── popup.html/.css/.js           # 默认 10 条、可配置 1–200 条的紧凑工具栏界面
│   └── manifest.json                 # 加载已解压扩展时使用的入口
├── tests/*.test.js                   # 逻辑、适配层、界面与文档契约测试
├── docs/adr/                          # 架构决策记录
├── docs/superpowers/plans/            # 实施计划
├── docs/testing/                      # 人工验收清单
├── package.json                       # 无第三方依赖的测试与校验命令
├── CONTEXT.md                         # 领域词汇
├── proposal.md                        # 已确认产品规格
├── README.md
├── README.zh.md
└── LICENSE
```

扩展使用原生 Manifest V3 JavaScript，不需要构建步骤。运行全部自动化测试：

```bash
npm test
```

运行 `npm run check` 可检查 JavaScript 语法、扩展清单和补丁格式。
