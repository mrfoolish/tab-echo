## 真实 Chrome 自动驱动预检

以下结果来自隔离 Chrome 配置中的真实扩展页面和 Service Worker，不替代下方人工验收：

- 扩展以 `0.1.3` 加载并启用，常规上下文 Service Worker 正常注册消息监听器。
- 关闭单个网页后，Popup 显示 1 条标题、网址和关闭时间完整的记录。
- 关闭包含两个网页的窗口后，生成一个完整 Group；子标签顺序与关闭前一致。
- 搜索只命中 Group 的第二个子标签时，仅渲染该子项，并显示“命中 1 / 2 个标签页”；底层 Group 仍保留两个标签。
- 单条软删除后记录进入同一上下文回收站；移回关闭记录后回到关闭记录列表且未打开网页。
- Group“全部重新打开”创建新窗口，并按原顺序打开两个网页。
- 设置页实测默认值为 `10000 / 留空 / 3`；`0` 会显示行内错误并聚焦字段；三个限制均可留空保存为不限制。
- 中英文和深色主题切换可立即生效；测试结束后已恢复英文、跟随系统和默认保留规则。
- 清空回收站会先展开页面内确认区；取消会保留数据，确认后才永久清空。
- 首次打开扩展页面时曾收到通用失败提示，扩展错误页记录 `Migration notice upgrade verification failed.`。根因是常规/无痕 split Worker 同时升级共享迁移通知时生成不同通知 ID；现已允许完整且兼容的并发升级结果胜出，并增加双 Worker 回归测试。后续人工验收需重新加载扩展并确认错误不再出现。

本清单用于真实 Chrome 环境验收，不表示以下项目已经通过。执行前在 `chrome://extensions` 以“加载已解压的扩展程序”方式加载仓库中的 `extension/` 目录，并保持 Service Worker 控制台可观察。

## 捕获与生命周期

- [ ] 常规窗口单独关闭一个标签页：弹窗出现一条单条记录，标题、网址和关闭时间正确。
- [ ] 常规窗口一次关闭包含多个标签页的整窗：生成一个 Group，顺序和所有子标签页完整。
- [ ] 让扩展 Service Worker 休眠后再关闭标签页：记录仍被捕获；重新打开弹窗后数据可读。
- [ ] 关闭最后一个无痕窗口：关闭事件在无痕上下文中保留；之后新开无痕窗口仍能读取。
- [ ] 重启浏览器：已持久化的常规记录仍存在；无痕数据行为符合 Chrome 对无痕会话的实际生命周期。

## 上下文隔离与无痕授权

- [ ] 未开启“允许在无痕模式下运行”时，确认产品不会暗示已捕获无痕记录。
- [ ] 开启该授权后，分别在常规和无痕窗口关闭内容：两个上下文的关闭记录和回收站互不可见。
- [ ] 在一个上下文修改共享偏好设置：另一上下文下次启动或读取时应用设置，但内容仍隔离。
- [ ] 常规和无痕完整页面分别只复用各自页面，不跨上下文切换或复用。

## Popup

- [ ] 无查询时弹窗按设置展示 1–200 条关闭记录，并始终提供“打开完整列表”。
- [ ] 搜索标题与网址，确认按设置上限展示精确结果；仅当结果超出上限时显示“查看全部 X 条结果”。
- [ ] 使用“打开完整列表”或“查看全部 X 条结果”跳转完整页面：`view` 与编码后的查询词正确传递并立即生效。
- [ ] 单条“重新打开”和 Group“全部重新打开”能打开网页，且原关闭记录不被消费。
- [ ] 将弹窗展示条数设为 10，并制造超过 10 条搜索结果：“移入回收站（10）”只移动当前展示项；“直接移除”菜单可分别移除当前显示 10 条或全部搜索结果，两种范围均先显示记录数与标签页数；取消、修改搜索词或按 Escape 不执行旧确认。
- [ ] 键盘 `/` 聚焦搜索，`Escape` 清空；Tab 顺序、焦点和按钮可访问名称正确。

## 完整页面与 Group 搜索

- [ ] 关闭记录、回收站、设置三个导航区可切换，刷新后仅记住导航区，不记住搜索词和页码。
- [ ] 分页可切换 25、50、100 条；前后翻页与查询变化后的页码重置正确。
- [ ] “按关闭时间 / 按域名”切换语义清晰；按域名时摘要、分页、移入回收站和直接移除均只作用于当前域名，“跨域标签组”显示组数与标签页数。
- [ ] 搜索只命中 Group 的一个子标签页时，仅显示该匹配项；Group 总数和完整快照不丢失。
- [ ] 展开/折叠 Group 后图标语义、焦点和命中高亮正确。
- [ ] 长标题、长网址、中英文长文案下无截断误导、横向溢出或按钮遮挡。
- [ ] 已关闭标签页始终显示距今关闭时长；回收站同时显示距今关闭时长和距今移入回收站时长。长网址只裁剪网址，不遮挡时间；hover 或键盘聚焦可读取完整时间。

## 回收站与破坏性操作

- [ ] 单条记录移至回收站：记录从当前上下文关闭记录消失，并完整出现在同一上下文回收站。
- [ ] 将搜索结果移至回收站：无需确认，且不包含未命中的隐藏重复记录。
- [ ] 将全部记录移至回收站：无需确认，范围覆盖底层全部事件，包括展示去重隐藏的旧单条记录。
- [ ] “移回关闭记录”把内容移回关闭记录列表但不打开网页；“全部移回关闭记录”和“移回 X 条搜索结果”均不表示重新打开网页；容量不足时整批拒绝且两边数据不变。
- [ ] 回收站单条记录直接展示“直接移除”，不显示“更多操作”；无需确认，移除后不可恢复。
- [ ] 关闭记录可“直接移除”，无需确认、不会进入回收站，操作反馈明确提示无法恢复。
- [ ] 完整页有搜索词时，“移除全部结果”覆盖全部匹配结果而非当前页；无搜索词时覆盖全部关闭记录。二者都先显示记录数和标签页数，取消、切换视图、修改搜索词或按 Escape 后不再执行旧确认。
- [ ] “清空回收站”使用页面内确认区；取消、切换视图或按 Escape 均不删除，确认后不可恢复，且不出现浏览器原生弹窗。
- [ ] 将回收站期限设为已能淘汰测试数据的值，确认其只按期限清理、不按数量清理。

## 设置、容量与迁移

- [ ] 默认设置为最多 10000 条、关闭记录天数留空、回收站 3 天。
- [ ] 三个可留空设置始终显示“不限制/永久保留且仍受浏览器存储空间限制”的说明。
- [ ] 分别保存空的条数、历史天数和回收站天数，确认不限语义生效。
- [ ] 输入 `0`、负数、非数字：阻止保存，显示对应字段行内错误并聚焦首个错误。
- [ ] 缩小条数或期限但不产生删除影响时直接保存；产生永久删除影响时先显示记录数和标签页数，确认后才保存并清理。
- [ ] 新增排除域名且命中已有历史或回收站时，保存提示与条数/期限影响合并展示且不重复计数；选择“仅保存规则”保留旧记录，选择“保存并移除命中项”只清理本次新增规则命中的数据，并保留 Group 中未命中的标签页。
- [ ] 设置页按保存与清理、弹窗显示、外观与语言、排除域名分组；保存前说明影响数字只统计当前常规或无痕上下文，另一上下文会稍后应用共享设置。
- [ ] 移动、移除、恢复和重新打开成功后提示不会被列表刷新立即清除，并可见约 5 秒；错误提示保留到重试或下一次成功。
- [ ] 人工制造 `chrome.storage.local` 容量不足：写入原子拒绝，既有记录/回收站不丢失，并显示可理解错误。
- [ ] 从旧版 `65536 / 30` 默认设置启动：自动迁移到 `10000 / 不限制天数`，回收站默认 3 天。
- [ ] 从旧版自定义设置启动：保留自定义值；损坏记录被跳过且不会阻止有效数据迁移。
- [ ] 一次性迁移提示：首次从 legacy 成功迁移后，Popup 或完整页面显示“已迁移现有关闭记录，其中 {count} 条损坏记录无法恢复。”；再次打开不重复显示。
